# **App Name**: Managerial Central

## Core Features:

- User Management: Add, edit, and delete user profiles, with detailed information fields.
- Employee Management: Similar to user management, but with employee-specific fields (department, job title, etc.).
- DJ Management: Handle DJ profiles with fields such as music genres, booking information, and performance history.
- Search Functionality: Implement a search bar for quick filtering across all managed entities.

## Style Guidelines:

- Primary color: Saturated, bright reddish-orange (#E64A19) for an active, eye-catching interface.
- Background color: Light desaturated red (#F9E7E4), creating a subtle, yet defined background.
- Accent color: Deep crimson (#9E0039) for highlighting important actions and elements.
- Body and headline font: 'Inter', a grotesque-style sans-serif font with a modern, machined, objective, neutral look.
- Use a consistent set of minimalist icons across all tabs.
- Design a clean, tab-based layout for easy navigation between users, employees, and DJs.
- Use smooth transitions and animations when switching tabs or displaying additional information.
